# Nova AI — Android Chatbot

Native Android WebView chatbot starter with demo chat and optional secure backend connection.

## Get an APK

Open **Actions** and select **Build Nova AI APK**. On successful builds, download the **NovaAI-Android-APK** artifact and extract `app-debug.apk`.

This project is a personal-testing prototype. AI responses require a separately deployed backend and OpenAI API billing. Never put an API key in the Android app or public repository.
